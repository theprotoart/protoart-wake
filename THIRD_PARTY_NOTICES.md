# Third-party notices

ProtoArt Wake 2 bundles no third-party code. It uses frameworks that ship with macOS (AppKit, WebKit,
IOKit, Carbon, ServiceManagement, UserNotifications) and fonts installed with macOS (for example
DIN Condensed, Marker Felt and Futura). The app icon and all artwork are original to this project.

Version 1 bundled Electron (MIT) and Chromium (BSD-3-Clause and others); those are no longer included.
